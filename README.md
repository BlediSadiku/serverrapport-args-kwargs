# Serverrapport met Python

Een oefening over functies, `*args` en `**kwargs` uit hoofdstuk 5 van Scripting with Python SNB1. Het programma toont een servernaam, statussen en aanvullende details.

## Uitvoeren

Vereist Python 3, zonder externe pakketten.

```sh
python3 03_serverrapport_args_kwargs.py
```

Er is gewerkt met een kopie van de echte homework-oefening; het origineel blijft ongewijzigd. De voorbeeldbeheerder is geanonimiseerd naar Demo.
